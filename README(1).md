# CSS Connect + Service Pulse — End-User Test

Prototype test site for Community & Student Services.

## Important
This is an end-user testing prototype only. Use sample information. Do not enter real scholar or family information.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `css-connect-pilot`).
2. Upload `index.html` and `README.md` from this package to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the Pages address after deployment.

## Testing purpose
The prototype is intended to test whether CSS staff can independently:
- start a new episode;
- find an existing episode;
- understand the episode history;
- add a touchpoint;
- pick up shared work;
- understand Service Pulse and Explore Time.

## Production limitation
This static prototype is not a secure case-management system. It does not provide production authentication, protected persistent records, role-based permissions, or a secure shared database. Do not use it for real scholar/family information.
